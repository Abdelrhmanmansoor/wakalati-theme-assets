# Wakalati theme assets

Public preview images for the Wakalati Salla theme's settings in the Salla dashboard.

- `options/` — one schematic per option of the theme's visual settings.
- `block-previews/` — the preview image of each home block.

Served through jsDelivr, pinned to a tag:
`https://cdn.jsdelivr.net/gh/Abdelrhmanmansoor/wakalati-theme-assets@v1/options/<file>.svg`

Generated by `scripts/option-previews/build.mjs` in the theme repository. Do not edit by hand.
